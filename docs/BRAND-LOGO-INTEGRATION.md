# ALI AL-FATEEH logo integration

- Original user-provided transparent PNG is stored at `public/ali-al-fateeh-logo.png`.
- Original artwork is copied without editing, recoloring, cropping or stretching.
- The logo is displayed on Deep Navy panels so the white lettering remains visible.
- Usage locations: application sidebar, admin login, loading state, Firebase configuration state, browser-print bills, payment receipts, ledgers and reports, and browser icon.
- It is rendered with the native 1774:887 aspect ratio using responsive width and automatic height.

No customer identifiers, Firebase secrets or financial calculations are embedded in the image asset.
